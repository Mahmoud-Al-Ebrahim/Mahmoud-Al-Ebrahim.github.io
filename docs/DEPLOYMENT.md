# Deployment

The site is a fully static export (`out/`). It is hosted free on GitHub Pages at
`https://mahmoud-al-ebrahim.github.io`, deployed by GitHub Actions on every push to `main`.

## First publish

1. Sign in to the GitHub CLI once:

   ```bash
   gh auth login -h github.com -w
   ```

2. From the project folder, run:

   ```bash
   bash scripts/publish-github.sh
   ```

   It creates the public repository `Mahmoud-Al-Ebrahim.github.io`, pushes the site as a fresh history (private planning notes are excluded), and turns on Pages deployment from GitHub Actions.

3. Watch the first run under the repository's **Actions** tab. When it is green, the site is live.

## Updating

Edit content (see `docs/ADDING_CONTENT.md`), commit, and push to `main` of the GitHub repository. The workflow in `.github/workflows/deploy.yml` lints, type-checks, runs the unit and end-to-end tests, builds and deploys. A failing test stops the deploy.

## Serving from a sub-path

To host the site at `https://<user>.github.io/<repo>/` instead of the root, set a repository variable `BASE_PATH` to `/<repo>` (Settings → Secrets and variables → Actions → Variables) and update `siteConfig.url` in `src/content/site.ts`.

## Other hosts

Any static host works: upload `out/` after `npm run build` (Netlify, Cloudflare Pages, S3). Share images are real PNG files in `public/og/`, generated by `npm run og` (which `npm run build` runs first).

## After deploying

- Open `/sitemap.xml` and `/robots.txt`.
- Paste a product URL into a chat app to check the share card.
- Run Lighthouse on the live URL in mobile mode.
- Validate a product page with https://validator.schema.org/.
